# Alejandro Castrillón - Personal Portfolio

Welcome to the repository for my personal website and portfolio. Built with modern web technologies, this site showcases my projects, experience, and skills in software engineering.

## 🚀 Live Demo
[https://alejandrocastrillon.dev](https://alejandrocastrillon.dev)

## 🛠️ Tech Stack

This project is built using:
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React](https://reactjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/) & [Magic UI](https://magicui.design/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **3D & Particles:** [Spline](https://spline.design/) and [tsparticles](https://particles.js.org/)
- **Language:** TypeScript

## ⚙️ Features

- 🎨 **Modern & Premium UI:** Designed with a curated dark mode palette (Night Blue, Tech Blue, Wine), glassmorphism, and micro-animations.
- ✨ **Interactive Backgrounds:** Integrated 3D scenes and particle effects for a dynamic and immersive user experience.
- 📱 **Fully Responsive:** Carefully crafted layouts for seamless viewing across mobile, tablet, and desktop devices.
- 🔍 **SEO Optimized:** Automatic sitemap generation, structured metadata, and clean routing for optimal search engine visibility.

## 🏃‍♂️ Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AlejoTPK/PaginaWebPersonal.git
   cd PaginaWebPersonal
   ```

2. **Install dependencies:**
   This project uses `pnpm` as the package manager.
   ```bash
   pnpm install
   ```

3. **Start the development server:**
   ```bash
   pnpm dev
   ```

4. **Build for production:**
   ```bash
   pnpm build
   ```
